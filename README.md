# 麦麦场景营养师（McFit Coach）

> 输入你的场景与目标，结合麦当劳实时菜单、营养数据与你的可用优惠券，算出最划算又吃得安心的套餐方案，并生成可视化营养报告。

## 这是什么

麦麦场景营养师是一个基于 **麦当劳 MCP（mcp.mcd.cn）** 能力开发的 WorkBuddy Skill。它把"想吃麦当劳又怕踩雷"的真实痛点，变成一套可执行的套餐推荐 + 营养可视化方案。

## 核心功能

- 🎯 **场景 / 目标驱动**：减脂期 / 带娃出游 / 加班补给 / 健身后 / 追剧宵夜
- 🥗 **营养约束求解**：基于麦当劳实时营养数据，在热量 / 蛋白 / 钠等维度内组合套餐
- 💰 **到手价测算**：调用 `calculate-price` + 你的可用优惠券，算出真实支付金额
- 📊 **可视化报告**：雷达图 + 三餐热量环形图 + 三态进度条（达成 / 缺口 / 超标）
- 🛒 **一键建单**：生成订单（付款仍由本人扫码完成，Agent 不替你付钱）

## 目标用户

- 想控制热量又不想戒掉麦当劳的减脂人群
- 带娃家庭、加班族、健身人群、夜宵党

## 安装 / 配置

1. 申请麦当劳 MCP Token：<https://open.mcd.cn/mcp>（手机号登录 → 控制台 → 激活）
2. 在 WorkBuddy 配置自定义连接器，配置内容见 `mcp-config.example.json`
3. 在 WorkBuddy 中打开本 Skill，输入你的场景与目标即可使用

## 使用示例

> **用户**：我是减脂期，今晚想吃麦当劳，帮我配一份不超过 600 大卡、蛋白够的套餐，用上我手头的券。
>
> **麦麦场景营养师**：拉取菜单与营养 → 组合 3 套方案 → 测算到手价 → 输出可视化报告。

## 网页版（产品级 PWA）

**在线体验：<https://mcfit-coach.app.workbuddy.host/?sharecode=YE4C4DCKKQ>**

麦麦场景营养师不只是一个 Skill——`webapp/` 是一个完整的单页产品（纯静态、零后端、数据全本地）：

- **四个视图**：今日仪表盘（营养进度环 / 连续记录）、配餐台（场景目标 / 菜单检索筛选 / 草稿组合）、报告中心（雷达图 / 供能占比 / 三态进度 / 营养师点评 / 7 日趋势）、我的（目标自定义 / 数据导出导入）
- **智能推荐引擎**：按「主食 + 小食 + 零卡饮品」结构在 152 个真实餐品中搜索约 5400 组组合，以热量偏差、蛋白缺口、钠/脂肪超标为评分函数取最优（`js/engine.js`，5 个场景实测均精准命中目标 ±1%）
- **真实数据**：152 个餐品营养数据来自麦当劳官方 MCP `list-nutrition-foods`（2026-10-24 实时快照），无任何虚构
- **本地持久化**：localStorage 存储目标 / 草稿 / 历史记录，支持 JSON 导出导入
- **PWA**：可安装到桌面/主屏，Service Worker 离线可用
- **测试**：`webapp/tests/` 下 71 个断言（引擎 45 + UI 冒烟 26），`node webapp/tests/engine.test.js && node webapp/tests/ui.smoke.js`

```bash

cd webapp && python3 -m http.server 8901
# 打开 http://127.0.0.1:8901
```
